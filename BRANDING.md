# SignalSift branding

Tool: **SignalSift**. Repository name: `signal-sift`.

The mark shows three signals converging into one pulse; teal and mint connect it to filtering and incident correlation. The README embeds this asset using a repository-relative path. This is a generated raster asset, not an editable vector master or a trademark/uniqueness clearance.

Created with the built-in image generation tool, not the fallback CLI. The final prompt was:

> Use case: logo-brand. Asset type: final logo PNG for the SignalSift GitHub repository and README. Create an original polished minimal technology identity for an alert correlation and observability analysis tool named SignalSift. Horizontal composition: a compact abstract symbol at the left, the exact wordmark "SignalSift" at the right. Symbol: three clear signal strands converge through a subtle S-shaped curve into one clean pulse, conveying filtering and correlation. Flat, crisp, vector-like edges, thick enough for small display, restrained geometry and generous negative space. Palette: vivid medium teal and a small mint accent; teal wordmark in a clean modern geometric sans serif, strong legibility. Text must read exactly SignalSift, capital S at the start and at Sift. Genuinely transparent alpha background, no white rectangle or checkerboard painted into the image. No gradients, glow, shadow, 3D effects, mockup, border, tagline or watermark. One horizontal logo only.

Visual inspection confirmed the wordmark reads SignalSift and the intended signal/pulse symbol is present. File inspection confirmed a valid PNG with a transparent alpha channel.
